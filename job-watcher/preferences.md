# Preferences & Learnings

- (2026-09-10) Always show full Task 1 + Task 2 tables/content directly in the final chat message — never just point to the saved .md file. Still save the run file to job-watcher/runs/ for memory, but the chat reply itself must contain the full tables.
- (2026-09-21) TASK 2 SCRAPPED. Do not search for, surface, or mention job openings at all (remote or in-office). Every future run = Task 1 only (AI funding radar). Skip seen_roles.md checks/updates entirely. Run output file = funding table only.
- (2026-10-05) Learning: aggregator search summaries sometimes mislabel round stage (e.g. a Series C getting called "Series A" in snippets) and sometimes resurface an old article without the year being obvious (e.g. a 2025 round reading as "2026" in a search summary). Always cross-check the round letter and exact announce date against 2+ sources with explicit dates before including a company — don't trust the first summary's stage/date label at face value.
- (2026-10-27) SCOPE WIDENED — applies this run and all future runs. Task 1 is no longer AI-only. Include:
    * Sectors: AI, fintech, tech, SaaS, financial services, and companies across any vertical.
    * EXCLUDE sectors: healthcare, medical services, pharma/biotech, mining, and any industry requiring field/on-site presence (i.e. where a non-tech growth hire couldn't work remote).
    * GEOGRAPHY (hard): company must be based OUTSIDE India. Eligible HQ regions = USA, UAE, Singapore, Europe (any), or similar — i.e. able/likely to pay in USD, AED, SGD, EUR (any currency stronger than INR). Drop India-HQ'd companies entirely.
    * STAGE (hard, unchanged): pre-seed, seed, Series A, Series B MAX. Nothing later. Rationale: this is the window where companies make their first non-tech / growth hires — Viivek's entry point.
    * Size signal (unchanged): still skip $500M+ total raised OR 500+ employees.
    * Window (unchanged): announced within last ~2–3 weeks of run date.
    * Table format unchanged (Company | Total Raised | Round | Announce Date | One-liner | Website | Founder LinkedIn/X). Add a "Sector" and/or "HQ" note in the one-liner so geography/vertical is visible at a glance.
- (2026-10-29) Learning: aggregators/trackers occasionally disagree on a company's HQ city/country outright (not just stage/date) — e.g. one run found a company whose own press release said Austin, TX but one aggregator (af.net) labeled it New Delhi, India. Given the hard India-exclusion rule, treat an unresolved HQ conflict the same as an unresolved stage/date conflict: don't guess either way — exclude and flag it explicitly for Viivek rather than silently including or dropping.
- (2026-11-02) Learning: search aggregators very frequently resurface rounds that are actually weeks-to-a-year old while labeling them as current (e.g. a 2025-10-01 pre-seed reading as fresh in a snippet, or an Oct 5-9 round surfacing in a "this week" query run on Nov 2). Always pull the explicit announce date from 2+ sources before counting a company toward the current window — don't trust a search tool's own "recent"/"this week" framing.
